# 旅冊 Travel Book — 美術素材包 v1

主題：日系清爽手帳風 / 抹茶灰綠、米白、柔和手繪與輕微紙張肌理。

## 檔案資料夾

- `brand/`: Logo、App icon、Favicon
- `hero/`: 首頁圖像與預留純 HTML 標題空間的 1600×900 背景
- `empty/`: 4 張無資料狀態圖（無行程／無景點／無照片／無旅伴）
- `features/`: 5 張功能介紹插畫（規劃／小冊／匯出／分享／旅行中）
- `covers/`: 1 張東京示範封面與 3 個封面方向參考
- `decor/`: 票券／紙膠帶／圖示／章節標籤等裝飾素材
- `guides/`: 風格板、色票與替代視覺參考
- `style-tokens.css`: 網站色彩、圓角、字型與簡易元件樣式

## 整合步驟

1. 將素材放到網站的 `assets/travel-book/` 內，保留資料夾結構。
2. 將 `style-tokens.css` 搬到同一層；在 `index.html` 內以 `<link rel="stylesheet" href="assets/travel-book/style-tokens.css">` 引入。
3. App icon 連結到網站既有 manifest；Favicon 指向 `brand/favicon-64.png`。
4. 在首頁先使用 `hero/hero-background-1600x900.webp` 搭配真正的 HTML 標題、文字、按鈕（不要在圖片裡再寫 UI 文字）。
5. 用 `empty/` 及 `features/` 的 WebP 檔放到對應頁面。網站推薦 WebP；需要印刷的封面使用 PNG。
6. `style-tokens.css` 的 `.tb-hero` URL 是相對 CSS 所在目錄；若你將 CSS 移到別處，請同步修正路徑。

## 注意

- 插畫以風格板內素材拆分而成，適合第一版網站展示與視覺原型；某些圖片含柔和紙感底色，**不是透明背景**。
- 封面中的示範地點、日期文字是圖片內容；實際使用者產生的小冊封面，應讓標題／日期由 HTML 與 CSS 即時產生。
- 這套素材原始插畫為 AI 產生後拆分，有些細節為概念視覺；原始輸出像素較小，**放大不等同提高印刷解析度**。實體成冊前須按最終尺寸確認清晰度。
- Logo 的圖形標誌可作初版識別；若需清晰 SVG 及不同尺寸品牌統一，建議再進行向量化精修。
- 不要直接覆蓋原本網站的功能 CSS。建議先在開發分支新增設計變數、觀察手機編輯器及列印樣式是否受影響。

## 實作原則

- UI 保持純 HTML 文字，禁止以圖片承載核心互動按鈕、欄位標籤、行程文字。
- 紙本模板與網站 UI 共用色彩，但應分開處理列印 CSS。
- 大字閱讀與省墨模式優先保障可讀性，不強制套用所有裝飾。
